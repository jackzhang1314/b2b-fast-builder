# 项目设计记录

此模板用于生成或补充客户项目的 `DESIGN.md`；按实际项目删减，不能把示例状态当作已确认事实。已有设计记录时合并，不覆盖。

## 上下文与状态

- 业务契约 / route matrix：记录实际文件位置。
- 本轮范围：新站 / 整体改版 / 某个模板；列出受影响页面。
- 状态：提议 / 待确认 / 已确认；记录日期与确认来源。
- 样式批准 / 真实内容批准：分别记录来源，不能互相代替。
- 客户明确要求保留与避免的内容：按真实反馈填写。

## 视觉方向

- 服务哪类买家，首屏要帮助他确认什么。
- 产品、证据、说明和 CTA 的阅读顺序。
- 内容密度、图片角色、字体层级与整体气质。
- 本项目的辨识点及其业务理由；不需要特效时明确不做。
- 默认专业、大气的 B2B 企业站：实物摄影、清晰分类与参数、克制配色、有秩序的网格和留白；列出本项目如何落实，而不是只写“高级”。
- 避免：产品区 SVG 插画充数、泛科技渐变/发光、重复图标卡片墙、虚构企业实力。

## 预览素材与客户资料

- 现有客户素材位置；不足部分的可使用摄影/AI 示意来源与预览标记。
- 哪些素材仅供参考不进入网站，哪些需在正式发布前替换：链接素材清单，不重复登记。
- 样式确认后已向用户发出的资料邀请、收到的文件与仍缺的必需项。
- 资料整理与“产品 → 参数 → 图片”待核对项：给用户简短清单，不要求填技术表。

## 设计规则与代码真源

| 角色 | 源码 / Token 位置 | 使用规则 |
|---|---|---|
| 主动作与颜色 | 填实际 CSS 位置 | 哪些动作使用，不复制整套色值 |
| 标题、正文、参数 | 填实际 CSS 位置 | 字体覆盖、层级、换行与可读性 |
| 间距与内容宽度 | 填实际 CSS 位置 | 页面和组件如何使用 |
| 产品图与场景图 | 填素材清单位置 | 比例、完整展示或焦点裁切 |

CSS 与内容模型维护实际值；本文解释意图，不形成第二套值或重复业务资料。

## 确认与回归

- 样板产物与构建版本：记录可复核位置。
- 桌面 / 手机截图及浏览器检查记录：记录路径，不能虚填。
- 用户已确认的共享规则与页面局部：分别记录。
- 未确认素材、已知问题与下一步：保持可见。
- 替换真实公司/产品素材后的复查结果与内容公开批准：不能沿用仅含预览图的截图代替。
- 之后修改遵循：先确定局部/模板/全站范围，改真源，构建与验证，再更新批准记录。
